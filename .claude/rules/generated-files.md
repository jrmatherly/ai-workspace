# Generated model-definition map

`src/modules/llms/server/gen/llms.defs.versions.ts` is generated by `tools/develop/gen-llms-defs/generate-llms-defs.mjs` (runs in `predev` and `prebuild`) from the files listed in `llms.defs.manifest.ts`. It is committed on purpose.

- Never hand-edit it. After changing any `*.models.ts` or the manifest, run `node tools/develop/gen-llms-defs/generate-llms-defs.mjs` and commit the result with the change. `--check` exits 2 when the committed map is stale.
- On a cherry-pick or merge conflict in that file, take the source model file, then regenerate instead of resolving hunks by hand.
- A new `*.models.ts` must be added to the manifest or the generator fails the build.
